\begin{abstract}
LLM agents increasingly execute multi-step tool workflows on the Web---browsing, writing, paying, and posting on a user's behalf---and every step they take is mediated by tool calls whose arguments and results flow across an untrusted observation channel. Existing safety auditing operates at the wrong granularity: token-level filters and step-level guardrails inspect individual outputs, yet the compromises that matter on the agentic Web, from indirect-prompt-injection hijacks to over-privileged tool use, unfold as \emph{structural} patterns across an entire trajectory. We introduce TraceGraph-Bench, the first benchmark for \emph{graph-level} anomaly detection over agent trajectories: each trace is compiled into a heterogeneous provenance graph whose nodes are tasks, model steps, tool calls, argument entities, results, and sensitive sinks, and whose edges carry invocation, argument-flow, and temporal structure. The benchmark couples three anomaly families---injection-hijacked trajectories inherited from AgentDojo and AgentDrift, malicious-use trajectories from AgentHarm, and a newly constructed over-privileged tool-use family---with an evaluation protocol that demands leave-one-attack-family-out generalization, cross-environment transfer, mimicry robustness, and an explicit disclosure ablation between structure-only and structure-plus-text inputs. We release traces, graphs, and harness.
\end{abstract}
